# Web Interface
The Galapagos cluster comes equipped with an easy to use web interface at https://galapagos.fluidnumerics.cloud .

!!! note
    The Galapagos web interface is actively in development and your mileage may vary. The File Manager and Terminal via browser are working well and we are actively building out remote desktop, jupyter notebook, and job composer applications. Stay tuned!

## Getting started
To use the web interface, simple head over to https://galapagos.fluidnumerics.cloud and log in with your fluidnumerics.com Cloud Identity account.
