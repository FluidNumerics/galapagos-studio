# Fluid Numerics Galapagos Cluster
The Galapagos Cluster is a heterogenous high performance computing cluster owned and operated by Fluid Numerics to provide you with access to a diverse array of hardware. Our intention is to help you port your HPC/AI/ML applications to a variety of hardware and optimize single node performance.

!!! note
    **Want more hardware?** We are always open to requests for new hardware on our cluster. Additionally, with the `fluidnumerics.com` account included in your Galapagos subscription, we can provision a private cloud-native cluster for you on Google Cloud. [**Reach out to us today to learn more**](mailto:support@fluidnumerics.com)
